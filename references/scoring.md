# 10 项打分口径

**这把尺子已拿 5 个真实 SOTD 和 1 个没得过奖的模板站校准过**（2026-10-13，过程见 lessons.md）：真实获奖站大多应在 9–10 分，模板站在 5–6 分。

**两套尺度别混**：这 10 项是我们自己的尺子，锚点见 `reviewer.md`「评分锚点」。Awwwards 评委自己的四项分（设计 40%、可用性 30%、创意 20%、内容 10%）尺度更严，只用来和参照站的真实评委分对齐，见 `reviewer.md`。

评分由独立评审来打（见 reviewer.md：定标卷校正、2 人取平均、和上一个最好版本并排比）。自评规则见 reviewer.md「用评审结果」。打分写进日志，汇报时不用逐项念给用户听。

| 维度 | 看什么 | 9 分长什么样 |
|---|---|---|
| 排版 | 字号层级、行高、字重、对齐、每行长度 | 不用读就知道哪里重要；中文行长适中；标题不超过 2 行 |
| 留白 | section 间距、块间距、卡片内边距 | 全站一套固定的间距等级，呼吸感稳定，既不挤也不空 |
| 视觉层级 | 每屏的焦点、主次按钮 | 每屏只有一个主焦点，主按钮一眼可见 |
| 色彩 | 主色和强调色的使用、对比度 | 一个强调色贯穿全站，对比度达到 WCAG AA，没有乱入的颜色 |
| 动效 | 入场、转场、状态变化 | 每个动效都说得出用途，短、顺、不挡路，招牌时刻有设计过的节奏 |
| 微互动 | 按下、悬停、输入、成功或失败的反馈 | 每次点击都有即时反馈，成功和失败都有清楚、讨喜的回应。营销站、概念站没有表单和结果状态时，看悬停、按下、切换、滚动联动的反馈是否即时、统一、有品牌感 |
| 响应式 | 五档宽度（375、768、1024、1280、1440）下的布局 | 五档都像为那个尺寸专门设计过的，不只是「没坏」。只做电脑版的后台工具：主要宽度都像专门设计过，手机宽度能看、不坏 |
| 原创性 | 有没有别人模板里不会有的东西 | 说得出 1–2 个专属于这个产品的设计点，而且服务于产品 |
| 好用程度 | 步骤数、可理解性、出错引导 | 新用户不看说明就能走完核心流程；常用操作一两步搞定。营销站、概念站：看懂这是什么产品、两次滚动内找到主按钮，只是 6 分的基本要求；到 9 分还要首屏就讲清和同类有什么不同，而且讲法是这个产品特有的 |
| 留存吸引力 | 用完还想不想回来 | 有真诚的回访理由：进度、成长、成就、回顾、快捷入口。工具类产品看复查、进度和提醒、结果能分享，不按等级、积分扣分。营销站、作品集、工作室官网看记忆点和转化：看完愿不愿意联系、会不会分享给别人，不看回访 |

## 哪些不打分

只有上表这 10 项打分。下面这些只看过没过，不打分，因为给它们打 7 分、8 分没有意义，还会让人觉得「差一点也行」：

| 检查 | 记法 |
|---|---|
| 布局体检（五档宽度的间距、对齐、溢出） | 过 / 不过，不过就列出具体位置 |
| 核心流程能否点通 | 过 / 不过 |
| 项目规矩（破折号、主题、控制台报错等） | 过 / 不过 |
| 性能和可访问性（Lighthouse、LCP、CLS、图片大小、键盘） | 过 / 不过，记数值 |
| 招牌时刻 | 每个标「未做 / 待打磨 / 完成」 |

这几项有任何一项不过，优先级都高于提分。招牌时刻做得好不好，看动效、微互动、好用程度、留存吸引力这几项的分数；状态只用来追进度，防止分数到了、某个时刻却还没做。

## 打分纪律

- **对照参照站打**：先问「摆在参照笔记里那几个获奖站旁边，这一项差多少」，再给分。
- **不许放水**：证据要求见 reviewer.md 规则 1。
- 分数只升不降是可疑的。改坏了要如实降分。
- 收工条件以 SKILL.md「什么时候停」为准，这里不重复。评分锚点见 `reviewer.md`。
